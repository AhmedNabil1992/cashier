## أولوية المراجع

توجيه صاحب المشروع الأحدث ثم قرارات V2.1 في الخطة الرئيسية، ثم التفاصيل والعقود والوحدات والمهام التابعة. المتطلبات والخطط السابقة والتتبع القديم محفوظة في الأرشيف التاريخي. أمثلة JSON والجداول لا تغير قرارات المنتج ضمنيًا.

مجلد `new` هو مكان الحزمة النشطة؛ أبقينا مساره لتجنب كسر الروابط. العقود مسودات وليست OpenAPI/JSON Schema معتمدة، وModules ملخصات مجال ترتبط بمهام القبول.
