# Vertical Profiles

## لماذا Profiles؟
Main ERP واحد، لكن شاشة البيع والـworkflow تختلف بشدة بين الأنشطة.

## RETAIL Profile
### Default
- Retail POS.
- Shifts/Cash حسب الاشتراك/السياسة.
- Printing.

### UX
- barcode-first.
- quick search.
- quantity/price.
- direct checkout.
- returns/exchange.
- customer optional.

### لا يحتاج افتراضيًا
- tables.
- KDS.
- courses.
- kitchen routing.

## RESTAURANT Profile
### Base
- Restaurant POS.
- takeaway/direct order.
- modifiers.
- kitchen notes.
- multi-tender.

### Optional
- Tables.
- KDS.
- Waiter.
- QR Ordering.
- Delivery.

## Profile ليس Package تجاري كامل
Profile يحدد UX/capability family، لكن كل Functional Plugin يبقى entitlement مستقل.
