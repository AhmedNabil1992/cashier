# Users & Security

## Runtime
`Cloud + Edge`

## Dependencies
لا توجد dependencies وظيفية إلزامية مبدئيًا؛ يظل Technical Edge Core مطلوبًا لأي Edge module.

## Scope
Cloud هو مصدر المستخدمين والأدوار. Edge يحمل نسخة تشغيلية للمصادقة Offline مع permission versions وmanager approvals وaudit.
