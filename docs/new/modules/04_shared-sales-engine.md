# Shared Sales Transaction Engine

## Runtime
`Edge`

## Dependencies
لا توجد dependencies وظيفية إلزامية مبدئيًا؛ يظل Technical Edge Core مطلوبًا لأي Edge module.

## Scope
قواعد مشتركة لكل POS: cart/order totals، taxes/service rules، discounts، payments، idempotency، refunds، receipt snapshots. لا يحتوي UI مطعم أو Retail.

## الربط بالتنفيذ

ملخص نطاق تابع لـV2.1، وليس Schema أوتقرير إنجاز. تفاصيل العمل والقبول: **E29/E10** في [قائمة التنفيذ](../../plan/EXECUTION_BACKLOG.md). بيانات وأحداث المجال تفصل بعد ERP Mapping.
