## ما أزيل من المحتوى النشط

- ادعاء أن ملف الخطة القديم هو المرجع الرئيسي الوحيد.
- اقتراح مقارنة Laravel Edge مقابل Node؛ Ubuntu وNode/TypeScript وMySQL أصبحت قرارات ثابتة.
- جدول المراحل P0–P9 الأسبوعي المنافس لـPhase 0–10 و5A/5B.
- إلزام KDS بالطاولات والطباعة الاحتياطية في تبعيات قائمة التنفيذ.
- الادعاء أن العقود ثابتة أوأن جميع ملفات Modules تحتوي تفاصيل بيانات وأحداث كاملة.
- اعتبار AI شرطًا مبكرًا للـPilot؛ اختبار صلاحياته عند تسليم Phase 9.

حُذفت الملفات الأربعة المكررة من المسار النشط بعد حفظ نسخها كاملة في الأرشيف. لا يزال الرجوع إليها ممكنًا دون جعلها مراجع تنفيذ موازية.

## فجوات باقية قبل التنفيذ

- العقود تحتاج JSON Schema/OpenAPI وأنواعًا وأخطاء وقيود إصدارات معتمدة.
- ملخصات Modules تحتاج Mapping للأصول الفعلية؛ لم يفترض اكتمال ERP Gap Analysis.
- Shared Sales والبنية التقنية لا تسعر ضمنيًا كبلجن مستقل؛ يعتمد الكتالوج تفاصيل تبعيات الوظائف وتسعيرها قبل التنفيذ.
- الوردية الآمنة شرط للعمليات النقدية المعنية؛ عدم شراء وظيفة لا يجيز تجاوز الضوابط.
- أرقام R/G محفوظة للتتبع ومفسرة في الملحق؛ المراحل الفعلية من V2.1 فقط.
- AGENTS يذكر إصدارات تختلف عن المراجعة السابقة؛ تحديثه ضمن تدقيق Phase 0 بعد مطابقة القفل. لم يعدل ضمن تنظيم خطط المنتج.
- التقديرات التاريخية لا تعتمد لـRetail وRestaurant مجتمعين؛ يعاد تقديرها بعد Phase 0.

## التحقق المنفذ

- فحص روابط الملفات المحلية في جميع ملفات Markdown النشطة: لا روابط مكسورة.
- فحص توازن code fences وصحة أمثلة JSON وعدم وجود تلف ترميز UTF-8.
- مطابقة بيان SHA-256 للملفات الستين داخل أرشيف ما قبل التعديل.
- إثبات وجود `info.md` الأصلي دون تغيير داخل الأرشيف.
- إثبات الاحتفاظ بمعرفات المهام الأصلية الـ159 ومجموعات INF/S/C القديمة.
- لم تشغل اختبارات التطبيق أوترحيلات البيانات؛ التغييرات توثيقية فقط.
